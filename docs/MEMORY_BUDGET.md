# Таблица бюджетов памяти

Правила (из v1): в бюджет пишется **пик**, не установившееся значение. Три точки на сервис: процесс без модели / модель загружена / после freeze. Обновляется при каждом добавлении сервиса. Стенд: nvidia-smi на Windows-стороне + torch.cuda.max_memory_allocated в healthcheck. Устройство: jtop/tegrastats, перед замером `nvpmodel -m 0 && jetson_clocks`, между прогонами — kill CUDA-контекстов.

Стендовые значения — предварительные (dGPU ≠ unified memory). Финальные — только с устройства, финалист — перемерен в закрытом корпусе.
