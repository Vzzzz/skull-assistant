# Фоновый режим: реакция без wake word

Предложение 2026-10-13 (владелец). Персонализированная система с личным контекстом может реагировать не только на обращение по имени, но и на «поток»: брошенную вскользь фразу, смену эмоционального состояния, тишину после долгой работы. Саркастичная реплика в ответ на бормотание над кодом — это и есть характер.

## Что это меняет в тракте

Сейчас: wake word → запись → STT → VLM → TTS. Микрофон «слушается» только после триггера.
Фоновый режим: **непрерывный** VAD → STT (CPU) → дешёвый фильтр «стоит ли реагировать» → VLM решает, что сказать, с **бюджетом инициативы**.

| Компонент | Что добавляется | Кандидаты | Бюджет |
|---|---|---|---|
| Непрерывный STT | STT работает на каждом VAD-сегменте, не только после wake word | faster-whisper base/small int8 (есть) | CPU% на Orin — замерить; на стенде base int8 в простое 0 %, при речи — ? |
| Эмоция/паралингвистика | оценка состояния говорящего по аудио (не по тексту) | **emotion2vec+ base/large** (90M/300M, 9 классов, funasr; русский — проверить на Dusha/RESD), SenseVoice-small (есть эмоции + события, но без русского) | CPU, сотни МБ; считать на сегментах с речью |
| Фильтр инициативы | решает, реагировать ли: длина фразы, адресована ли кому-то, эмоция, время с последней реплики черепа | правила + маленький промпт к VLM («это обращение, бормотание или разговор с другим?») | дёшево |
| Бюджет инициативы | не больше N незапрошенных реплик в час, тишина в «рабочем» состоянии, «тише» (KWS) обнуляет бюджет на час | политика в диспетчере | — |
| Самоэхо | череп слышит себя → аппаратный AEC (ReSpeaker Lite, D-013) становится обязательным, а не желательным | | |

Приватность: всё офлайн, транскрипты фонового режима в память не пишутся без явного «запомни» (M6) — иначе память замусорится.

## Как проверять (замеры до проектирования)

1. **Стоимость непрерывного STT** на стенде и Orin: CPU% и латентность при 10 мин бытового звука (радио/подкаст как нагрузка). Гейт: ≤ 1 ядро Orin в среднем. **Стенд закрыт T-038 эт. 2 (2026-10-27):** GigaAM v3 + voice id в фоновом режиме — 1.2–1.3 % ядра в среднем, пик 29.7 % (окно 5 с), RSS пик 432 МБ; Orin — ×3–4 (T-010).
2. **Эмоции на русском**: emotion2vec+ base vs large на 100 фрагментах (Dusha — открытый русский корпус эмоциональной речи), accuracy и RT на CPU. Гейт: лучше случайного заметно (≥ 0.5 weighted F1 на 4 базовых классах) при RT ≤ 0.2.
3. **Ложные инициативы**: час записи рабочего дня (без черепа) → сколько раз фильтр решил бы «реагировать»; цель — единицы в час, не десятки. **Закрыт живьём T-038 эт. 2 (2026-10-27):** 3 ч 24 мин бытового фона (кухня, голоса семьи) — 0 ответов из 85 транскриптов; подкаст 30 мин — 0; бормотание владельца — 7 ответов из 14 (см. ниже).
4. UX: 10 сценариев «бросил фразу → реплика» с живым человеком, субъективная оценка уместности.

## Ambient-lite (2026-10-24)

Владелец: «ambient может оказаться сходу более полезной фичей, чем wake word». Урезанный вариант без эмоций и бюджета инициативы — **T-038**: триггер по началу речи вместо KWS (KWS остаётся для сервисных слов), седьмая метка роутера `aside` («сказано не мне») с политикой «молчать, в историю и память не писать», имя «Костян» в транскрипте — обращение без вопроса к модели. Проверка в два слоя: текстовый файл `research/eval/ctx_probe_ambient.jsonl` (70 реплик: обращения, бормотание, кот, телефон, гость, телевизор, подкаст, созвон, радио; поле `addr_expect`) → precision/recall по «ответить»; затем 30 минут фона на стенде. Замеры 1 и 3 из списка выше закрываются этапом 2; замер 2 (эмоции) остаётся на потом. Следствие: непрерывное слушание в полудуплексе означает глухоту на каждую реплику черепа → AEC (ReSpeaker Lite, D-013) поднимается в приоритете. У MILO (P-021) триггера слушания и инициативы нет вовсе.

**Итог этапа 1 (2026-10-24, D-029):** по тексту адресат не определяется — precision 0.36 при recall 0.95; модель узнаёт жанр (эфир, созвон, звонок), но не бытовые фразы. Фильтр «реагировать ли» становится **многомодальным**: голос владельца (верификация по эмбеддингу, CPU) + поза головы с камеры («лицом к черепу») + состояние разговора; текст — вето на эфир. Это и есть переработанный этап 2 T-038; замер 2 (эмоции) по-прежнему потом.

**Режим «уточки» и взгляд-триггер (владелец, 2026-10-24, вечер).** Основной сценарий фонового режима — разговор с ассистентом при фокусе на работе («жёлтая уточка»: глаза в мониторе, руки в коде, обсудить что-то пространное, не меняя фокуса). Поэтому поза головы — не фильтр адресата (он бы молчал именно тогда, когда нужен), а **триггер**: взгляд на черепе ≥ 2 с = обращение без слов (T-031). Порядок: voice id (T-039) → взгляд-триггер (T-031) → сцена с камеры как контекст роутера и «пора ли говорить» в режиме уточки (три действия: слушать / «угу» / ответить; пауза — сигнал, P-030) → разделение источников только если замер покажет перекрытие голосов (Q-054).

**Итог этапа 2 (живой замер 2026-10-27, `research/bench/results/ambient_2026-10-27.md`) — гейт не пройден.** Чужие голоса отсекаются надёжно: voice id не дал `owner` ни одному чужому голосу за 4 ч (семья, подкаст, эхо собственного ответа черепа), вето «Алло» держит звонок целиком (0 из 8). Провалы — в решении «отвечать ли владельцу»: (1) **каскад ENGAGED** — первое ложное «да» уточки на бормотании открывает окно 30 с, в окне отвечается всё, каждый ответ окно продлевает: 7 ответов из 14 бормотаний подряд, пока не случилась пауза > 30 с; вне окна уточка промолчала на 6 из 6; (2) **пропуски в зоне `uncertain`**: 2 из 12 обращений без имени получили 0.416 / 0.429 < `threshold_high` 0.45 → молчание; (3) **глухота на непрерывном эфире**: подкаст держит детектор «в речи» 10–18 мин подряд (уровень не падает ниже 0.8 × порога, фон вне речи не обновляется) — обращение в это время не откроет фразу; (4) `ack` («угу») не выдан ни разу — правило требует точку в конце реплики, punct-STT её часто не ставит. Цена фонового режима: wakeword 41 МБ вместо 176, STT ~1 % ядра; ответ на ~1 с позже (STT ждёт паузу до 2 с для уточки). По умолчанию остаётся `trigger: kws`; D-029 «режим слушания по умолчанию» — решение владельца по итогам.

## Место в плане

Отдельный трек после M4-доделки и M5: требует работающих barge-in (иначе череп не заткнуть) и AEC. Первые два замера можно делать на стенде в любой момент — они не зависят от остального. Для статьи это глава «инициатива ассистента и её цена» — тема, которой у соседей нет.

Связано: D-013 (AEC, KWS «тише»), TTS_TRACK §4, M6 (что из фонового попадает в память), TASKS T-011, UX_BACKLOG U-001 (музыка с фона).
