# Журнал сессий исследователя

Замена истории чата. Одна запись — одна сессия ядра, 5–15 строк, пишется в конце сессии (`docs/agents/RESEARCHER.md` §2). Новые записи **сверху**. Формат:

```
## 2026-MM-DD · <тема сессии>
Обсуждали: …
Решили: … (D-NNN, T-NNN, Q-NNN)
Открыто: … (что не доведено, что ждём от владельца)
Владелец: «…» — реплики, которые влияют на план, но не оформлены записью
Коммиты: <hash или диапазон>
```

Исполнитель журнал не ведёт — его отчёты в `TASKS.md` «Закрытые».
