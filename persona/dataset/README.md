## Файлы

| Файл | Что | Кто пишет |
|---|---|---|
| `user_lines.jsonl` | реплики пользователя (бытовые, вопросы, просьбы, провокации) — без ответов | владелец (30 мин в будни) + синтез ситуаций |
| `dialogs.jsonl` | диалоги с ответами учителя, прошедшие судью | `research/persona/gen_dataset.py` (T-020) |
| `negatives.jsonl` | плохие ответы с причиной — для отбора/DPO-шага | из отбракованных судьёй + вручную |
| `holdout_lines.jsonl` | 10 % реплик, не идущих в обучение — для A/B | скрипт |

## Формат `dialogs.jsonl` — одна запись на строку

```json
{"id": "d0001", "source": "distill-26b" | "owner" | "synthetic", "persona_version": "v3",
 "turns": [{"role": "user", "content": "..."}, {"role": "assistant", "content": "..."}],
 "judge": {"model": "claude-fable-5-1 (chat)" | "qwen3.5:9b", "score": 4, "why": "..."},
 "tags": ["быт", "не-знаю", "арифметика"], "notes": ""}
```

`user_lines.jsonl`: `{"id": "u0001", "text": "...", "tags": [...], "context": [необязательно: 1–2 предыдущих обмена]}`.

## Правила курирования

1. **Ничего из eval-диалогов** (`research/eval/ctx_probe_dialog.jsonl`, будущий T-008): ни реплик, ни якорей (Бублик, Дима, 4712, кинза, батарейки) — иначе CTX-1 перестаёт измерять. Скрипт проверяет пересечения по нормализованным строкам.
2. Учитель — `gemma4:26b-a4b-it-mtp-q4_K_M` с промптом v3 (потолок семейства); ответы проходят судью, берутся только ≥4; ответы длиннее 60 слов — в `negatives` с причиной «длинно», если не просили подробностей.
3. Русский, «ты», имя Костян; без смайликов, извинений, «как ИИ».
4. Оговорка на неизвестное — отдельный тег `не-знаю`, не меньше 10 % записей (вымышленные приборы, новости, погода).
5. Арифметика — с выкладкой, итог в конце, тег `арифметика`, 5–10 %.
6. Объём первой итерации: 300–500 обменов (в том числе ~50 от владельца), затем A/B.
