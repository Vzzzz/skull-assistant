# persona/

- `system_prompt.md` — текущий промпт персоны (сейчас продублирован в `services/brain/responder.py`; вынос в файл — задача рефакторинга brain).
- `dataset/` — курируемый датасет реплик для QLoRA (M9). **По умолчанию не публикуется** (`.gitignore`): содержит бытовой контекст. Решение о публикации очищенной версии — при пороге портфолио №3.
- `phrases/` — фиксированные фразы персоны (реплики перехода режимов, приветствия, реакции на триггеры) для офлайн-рендера в wav (см. `docs/TTS_TRACK.md` §3).

Перед публикацией репозитория проверить промпт и датасет на личные данные (имена, адреса, распорядок).
