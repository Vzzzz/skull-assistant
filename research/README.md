# research/

Всё, что измеряет, сравнивает или обучает. Ничего отсюда не запускается юнитом на устройстве.

```
bench/     замеры ресурсов: память VLM × контекст × KV, tok/s, TTFT; со-резидентность (M5)
eval/      оценочный набор: диалоговые промпты в образе, vision-кадры, tool-calling кейсы, длинные диалоги
tts/       bake-off TTS, синтетический датасет для своего голоса, обучение Piper (docs/TTS_TRACK.md)
```

Правила:
- Каждый скрипт пишет результат в `<папка>/results/` (в git попадают только `.md`-сводки; сырые CSV — по решению).
- Замер без записи в `docs/MEMORY_BUDGET.md` или `docs/DECISION_LOG.md` считается не сделанным.
- Протокол сопоставимости с jetson-ai-lab: W4A16, ISL/OSL 2048/128; на устройстве — `nvpmodel -m 0 && jetson_clocks`, между прогонами kill CUDA-контекстов.
