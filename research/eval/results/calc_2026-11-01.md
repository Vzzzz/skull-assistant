# T-015 — арифметика через инструмент `calc`: проверка через шину (2026-11-01)

**Что сделано:**
- **`core/numbers_ru.py`** — минимальная нормализация текста из STT до brain и памяти:
  - время словами → ЧЧ:ММ («в половине двенадцатого», «без четверти восемь», «в восемь сорок»);
  - числительное в начале фразы → цифры;
  - продиктованный код из ≥ 3 цифр → одно число («4 7 1 2», «четыре семь один два» → 4712);
  - `to_digits` — числительные в цифры только на копии, для извлечения выражения.
- **`services/brain/tools.py`:**
  - `calc` — арифметика через `ast`: числа, `+ − × / // % **`, скобки, `round`/`abs`; без `eval`, ограничение степени и величины, ошибка → `None`;
  - `extract` — «X % от Y», скидка, время + длительность («ехать час тридцать пять», «через полтора часа»), арифметика словами.
- **В brain:** метка роутера `calc` → справка «(вычислено: … = …)» после реплики, префикс `CALC_DONE` («назови в образе, не пересчитывай»). Не извлеклось — прежний префикс «по шагам».

**Через шину** — реплики владельца, звук заглушён, история восстановлена:

| Реплика | Метка | Справка | Ответ |
|---|---|---|---|
| Сколько будет семнадцать умножить на двадцать три? | calc | 17 × 23 = 391 | «Семнадцать на двадцать три — триста девяносто один.» |
| Вещь стоит две тысячи четыреста, скидка пятнадцать процентов. Сколько платить? | calc | 2400 − 15 % = 2040 | «Две тысячи сорок.» |
| Я выехал в восемь сорок, ехать час тридцать пять минут. Во сколько приеду? | calc | 08:40 + 1:35 = 10:15 | «10:15.» |
| Выйду в восемь сорок, ехать час тридцать пять. Во сколько буду на месте? | calc | 08:40 + 1:35 = 10:15 | «10:15.» |

- **CTX-1 math — 3 из 3**, вызовов модели — роутер + один ответ.
- **Ложные `calc`:** 33 реплики владельца из части 2 гейта T-046 (`mode_gate_2026-10-31_2_bus.json`) через роутер с историей — метка `calc` 0. Извлекатель сам по себе — ни одного вычисления на 44 репликах; нормализация не изменила ни одну.
- **Тесты:** `tests/unit/test_numbers_ru.py`, `tests/unit/test_tools.py` — задачи CTX-1 math/probe, 21 своя реплика, идемпотентность, отказы `calc`.
