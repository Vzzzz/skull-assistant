# eval/ — оценочный набор (долг Фазы 0)

| Файл | Содержимое | Объём | Статус |
|---|---|---|---|
| `dialog_prompts.jsonl` | реплики пользователя в бытовом контексте, ожидаемый стиль ответа в образе | ~20 | нет |
| `vision_frames/` + `vision_cases.jsonl` | кадры «комнаты», вопрос, pass/fail-критерий | ~10 | нет |
| `tool_calls.jsonl` | запрос → эталонный JSON вызова инструмента | ~15 | нет |
| `long_dialogs/` | 1–2 диалога по 30–50 реплик для проверки дрейфа персоны | 1–2 | нет |
| `tts_lines.txt` | 10 реплик персоны + 5 сложных (числа, омографы, длинные) для сравнения TTS | 15 | нет |

Формат jsonl: `{"id": "...", "input": "...", "expect": "...", "tags": [...]}`. Прогон — `run_eval.py` (появится вместе с первым набором).
