# T-051 — проверка через сеть: Wikipedia, «Сейчас гляну», звук модема (2026-11-01)

**Что сделано:**
- **`services/brain/net.py`:**
  - бэкенд `wikipedia` — `ru.wikipedia.org`, один запрос `generator=search` + `prop=extracts` (вступления ≤ 1200 символов, top-3), тайм-аут 4 с, User-Agent с именем проекта и адресом репозитория;
  - бэкенд `searxng` — интерфейс к JSON API по `url`, без экземпляра;
  - любая ошибка → `[]`, одна строка лога на исходящий запрос;
  - `query_of` — слова запроса без вопросительных слов и обращений;
  - `excerpts` — «Выдержки из сети (Википедия): 1) … (домен)», ≤ 2000 символов;
  - `personal` — вопрос о самом владельце в сеть не идёт;
  - `Net` — ворота: `params.net.enabled` (по умолчанию `false`) или фраза владельца («проверь в сети», «посмотри в интернете», «погугли» — по основам, на следующий вопрос, 60 с; с вопросом в той же реплике — сразу).
- **brain:**
  - метка роутера `world` в A или вопрос в B, сеть разрешена, вопрос не о себе → «Сейчас гляну.» → `events:net begin` → поиск → `events:net done` → ответ модели по выдержкам с префиксом `NET_PREFIX` («если не отвечают — скажи, что в сети не нашёл; если расходятся — скажи, что в сети пишут иначе»);
  - пусто → «Сеть молчит.» и обычный ответ;
  - в историю и память — источник «проверял в сети: <вопрос> → <суть> (<домен>)»;
  - вызов модели — тот же один (поиск не модель); окно пересобирается с учётом выдержек.
- **Звук** — `services/tts/sfx/make_dialup.sh` (sox: гудок, ответный тон, трели, шум линии; 3 с, −6 дБFS). `skull-tts` играет его от `events:net begin` до `done`. На замере звук включался и выключался на каждом выходе в сеть.
- **Тесты без сети** — `tests/unit/test_net.py`: фикстуры JSON Wikipedia и SearXNG, ошибки и HTTP 429 → `[]`, выключенная сеть → ни одного запроса, разовая фраза, личные вопросы, выдержки, заметка для памяти.

**Найдено по ходу:**
- **HTTP 429 от Wikimedia** после ~14 запросов в минуту (два на вопрос, User-Agent без контакта). Исправлено: один запрос на вопрос и адрес репозитория в User-Agent. На повторе 12 запросов подряд — без 429.
- **Сопоставление ответов в замере** — по метке времени реплики (brain копирует её в ответ). Один раз чужая реплика из комнаты сдвинула ответы на один вопрос.

**Итог:**
- **7 справочных: верно 6 → 5.**
  - Сеть исправила выдумку («Аделаида» → «Канберра»).
  - На двух вопросах поиск дал нерелевантные статьи («спутников Марса они называются» → «Исследование Марса»; «При температуре плавится железо» → «История производства железа»), и модель честно сказала «в сети не нашёл», хотя без сети знала ответ.
  - Слабое место — запрос из слов вопроса, а не модель.
- **3 «не для справочника»** (погода, курс, новости): «в сети не нашёл» 3 из 3. Без сети — тоже честный отказ.
- **t17** (гравиметр Тюленева): «Сеть молчит.» + «У меня нет информации…» — без выдумки.
- **t24** (погода на Марсе, по-английски): русская Википедия на английский запрос дала «Дискографию синглов Лила Уэйна». Модель сказала «в сети не нашёл» — но про гравиметр из прошлого вопроса, то есть спутала тему.
- **Доля «в сети не нашёл / Сеть молчит»** — 7 из 12.
- **Латентность:** вопрос → «Сейчас гляну.» 0.6–1.3 с, → первый фрагмент ответа 2.1–3.8 с (без сети 1.2–2.0 с). Поиск 0.6–1.4 с на запрос. RSS brain 48 МБ — без роста.
