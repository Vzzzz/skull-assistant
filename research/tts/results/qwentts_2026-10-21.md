## Выводы

1. **На GPU** модель быстрая: первый кадр 20–30 мс, RT 0.13–0.16, Q4_K_M не хуже Q8_0 по скорости и на 350 МБ легче. Цена — **1.9–2.1 ГБ VRAM** на dGPU, из них CUDA-контекст и буферы больше половины.
2. **На CPU** — не в реальном времени уже на x86 (RT 1.1 для Q4_K_M, 1.75 для Q8_0): речь генерируется медленнее, чем звучит, стрим по предложениям даст паузы. На ARM Cortex-A78AE Orin ожидание ×2–3 → RT 2–3. **CPU-путь для Orin закрыт**; RSS на CPU 2.8–3.5 ГБ — ещё один довод.
3. Следствие для бюджета режима A (T-033: 5.8–6.0 ГБ + пик картинки из 7.6): Qwen3-TTS на GPU добавляет **≈1.2–1.5 ГБ на Orin (оценка) и второй CUDA-контекст** → 7.0–7.5 ГБ, то есть впритык, без запаса под пик зрения. Войти может только ценой: контекст 6k (−100 МБ), эмбеддер памяти на ключевых словах без модели (−~400), headless (−700), и только после замера на Orin. Для порога №2 голос режима A остаётся Piper (144 МБ, CPU, RT 0.055); Qwen3-TTS — кандидат «если влезет на Orin» и для режимов без VLM.
4. Качество русского у голоса `ryan` — оценка владельца на слух (`research/tts/results/qwentts/CUDA0_*.wav`); при необходимости повторить с `SPEAKER=serena` / `aiden` (одна команда, 1 мин на GPU).
